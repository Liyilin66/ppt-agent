# 2 分钟演示脚本

准备：仓库在 main，`.env` 已配置，提前生成好一份 PPT 兜底；打开 Claude Code（已接入 ppt-agent MCP）和 PowerPoint。

| 时间 | 画面 | 操作与旁白 |
|---|---|---|
| 0:00–0:15 | README 首屏 | 「大模型已经能做 PPT 了，这个项目做的是给管理层用的那种：基于一份报告，每页能追到原文页码，改起来也方便。」 |
| 0:15–0:45 | Claude Code | 发送：`帮我做一个给新员工的 AI 工具培训 PPT`。展示它一次问一个问题；回答一题后，说「模糊需求它会问清楚」。 |
| 0:45–1:10 | 新对话 | 发送详细需求和 PDF 路径。展示只问一个问题就开始：「需求详细就不多问。」这里切到提前生成好的结果，不等几分钟。 |
| 1:10–1:40 | PowerPoint 打开成品 | 翻执行摘要、大数字页、表格、行动路线。放大页脚页码，打开 PDF 对应页对照一个数字；再直接改一个字、改一个图表数据，说明是原生元素。 |
| 1:40–1:55 | Claude Code | 发送 `把第 5 页改成对比形式`，展示 `revise_deck` 只改这一页（可切到提前录好的结果）。 |
| 1:55–2:00 | README 实测表 | 「方法和局限都记在仓库里，包括和 Claude Code 比还差在哪。」 |

诚实提示：不要说「比 Claude Code 好」，也不要说「数字绝对准确」。可以说：能追到页码，有规则核对，核对不是语义判断。
