# 视觉升级计划（2026-11-09）

**目标**：同一提示词下，盲评至少排到第二，并和 Claude Code 看着是同一档。只做这一轮；还是第三就停止打磨版式，改成让宿主模型设计页面、ppt-agent 提供检索和核查。

**基准**：`data/jobs/7d76cd90070f45dd8510b05b0515d671`（我们）对比 `演示文稿1.pptx`（Claude Code）、`演示文稿2.pptx`（Codex）。我们：21 个数字，0 图表 0 表格，内容铺到约 75%。

分支 `feat/visual-upgrade`（从 `feat/mcp-clarify` 开出）。只改 consulting 风格的整份结构，其他风格共享版式改进。

## 1. 版式引擎
- 总结句固定贴在内容区底部，内容区撑满中间，不再留下半页空白。
- 卡片高度可拉伸，内容在卡片内居中，避免半空卡片。
- 按内容自动放大字号，直到接近铺满。

## 2. consulting 风格加重
- 深色封面（左侧色块 + 右侧章节列表）、深色章节页。
- 浅灰卡片底代替细线；标题更大，标题下加粗短线。
- 版式词汇换成更有分量的组合。

## 3. 新版式
- `table`：原生表格。
- `metrics:hero`：一个超大数字色块 + 右侧支撑指标。
- `summary`：执行摘要（标签色块 + 结论 + 依据）。
- `roadmap`：带时间轴的行动路线。

## 4. 整份结构（consulting）
- 封面 → 执行摘要 → 章节页 + 内容 → 行动路线。
- 执行摘要和行动路线在所有内容页写完后，看着全稿生成；生成失败时退回确定性内容。
- 不超过 24 页时大纲控制在 3 个章节，才放得下章节页。

## 5. 内容
- 标题写结论，带上最关键的数字；每页尽量用 2 个以上具体事实。
- 有数字的页优先分到图表、指标、表格；限制对比和时间线的占比。
- 放宽字数上限；把全稿标题传给每一页，减少重复。
- 页脚用模型引用并已通过核对的页码，不再列出送达的整段范围。

## 6. 验收
1. 全部测试通过。
2. 样例经 PowerPoint 导出，无溢出。
3. 用原提示词真实生成，PowerPoint 逐页检查。
4. 三份随机改名 A、B、C，交给 Jay 盲评。
