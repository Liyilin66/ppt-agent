# 降低版式重复率计划（2026-11-10）

**问题**：不同版式共用一个页面骨架，很多版式都是一排等宽卡片；选版式只避开最近 3 页。100 页时重复感会很明显。

**验收**（离线 100 页测试 + 真实 100 页运行）：
- 任何一种构图占比不超过 12%（真实运行里内容决定分布，超标如实记录）；
- 同一骨架不连续超过 2 页；
- 等宽卡片类不连续超过 2 页；
- 真实生成 100 页，PowerPoint 导出后逐页看。

## 改动（consulting 风格）
1. **四种页面骨架**：标准；深色通栏标题；结论放在标题下方；左侧深色标题栏（结论也在栏内）。骨架和构图相互独立，放不下时退回标准骨架，不删内容。
2. **按全局使用次数选构图**：优先整份用得最少的，同时避开最近 3 页和连续的等宽卡片。
3. **长文档节奏**：连续 6 页没有观点页时，安排一页整页深色观点页。
4. **两个组合版式**：`chart:cards`（图表 + 填色解读卡），`points:figure`（大数字色块 + 要点列表）。

不做：模型自由排版；继续加别的版式。这一轮之后样式不再动。
