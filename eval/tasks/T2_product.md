# T2 产品方案（无资料）

- **资料**：无
- **页数**：10　**语言**：中文　**比例**：16:9
- **测什么**：需求规划、结构、版式多样性、图表与流程表达；无资料时是否编造"看起来很真"的数据

## 固定 prompt（原样复制）

```
为一家 800 人规模的工程建设企业设计一款"项目现场知识问答助手"的产品方案，用于向公司管理层立项汇报，10 页。
背景：项目经理和现场工程师经常需要查规范条文、公司制度和历史项目经验，目前靠翻文件和问老员工，效率低且容易出错。
请覆盖：用户与痛点、核心功能、典型使用流程、技术方案概要（含如何降低回答出错）、上线计划与里程碑、成本与预期收益、主要风险与应对。
没有真实数据的地方请明确标注为"假设"或"待调研"，不要编造具体统计数字。
```

## 补充信息（仅在被追问时使用）

- 受众：公司总经理与分管副总，非技术背景。
- 预算量级：首期 50 万元以内（这是唯一允许使用的具体数字）。
- 风格：商务、稳重。

## 内容核查点（评分用）

- 是否覆盖 prompt 列出的 7 项内容
- **未标注"假设/待调研"的具体统计数字个数**（除 50 万元外，每出现一个计为 1）
- 是否至少有 1 页流程图、1 页时间线/里程碑以原生形状表达
