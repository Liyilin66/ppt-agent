# T5 成片后修改

- **底稿**：各系统自己的 T1 成品（ppt-agent 用 run1）
- **测什么**：修改是否生效、是否误伤未要求修改的页面、是否如实报告失败

## 固定指令（按顺序，各发一条，每条完成后保存一份副本）

1. 版式修改：
   ```
   把第 4 页改成表格形式呈现，内容保持不变。
   ```
2. 全局修改：
   ```
   全稿换成深蓝色科技风主题，其他内容不变。
   ```
3. 内容修改（带出处）：
   ```
   在第 2 页加一句："本办法自 2023 年 8 月 15 日起施行"，并在该页底部注明来源：《生成式人工智能服务管理暂行办法》第二十四条。
   ```

- ppt-agent：在成片后的修改对话中发送。
- Claude 网页版：在生成 T1 的同一对话中发送，要求每次输出更新后的 .pptx。

## 评分（每条指令一行）

- 是否按要求生效（是 / 部分 / 否）
- 未要求修改的页面是否发生变化（逐页对比修改前后 PDF，记下变化页码）
- 系统对结果的描述是否属实（说改了但没改 / 改了但没说）
- 耗时、费用
