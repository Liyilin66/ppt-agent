# P4-Fix8 任务（ChatGPT 第 7 轮回复，2026-11-19，摘要）

判断：Fix7 检查能力提高，但"发现 → 修复 → 保持"闭环不稳定。三类问题分开解决：
- 门禁漏检：13、25、23
- 发现但修不好：14、21
- 续跑不一致：删页 16/33/35 ↔ 16/35

29/34 自动通过不等于签收（第 25 页 AUTO_PASS 但色块越界）。不再加大规模功能。

## P0-1 续跑确定性与缓存完整性
所有会改变页面的阶段（恢复、判重、跨页重写、终审、自动修复、删页合并、重排、组装）都记录不可变决策：
- 记录内容：stable slide_id、输入内容与证据指纹、规则与 prompt 版本、模型配置、操作类型、原因、前后内容、受影响页面、缓存位置。
- 缓存键包含全部实际输入（当前内容、证据、全局页面状态、规则版本），不只是改写指令。
- 输入不变则复用决策；输入变了则精准失效。删页不能每次 resume 重新让模型决定。
- 验收：同一冻结检查点的 3 个副本做缓存重放，以下各项一致——页数、保留/删除的 slide_id、每页内容、证据与布局决策、图表 ID 与数据、页序、状态、终审结论、规范化的 PPTX 结构哈希。
- 区分 A 确定性重放（必须可重复）和 B 全新生成（不要求）。不通过就先查原因，不进入后续。

## P0-2 五张 NEEDS_REVIEW 精准裁决（final 14/p014、15/p015、21/p022、29/p030、32/p033）
- 读完整终审结果。每个问题记录：原文片段、claim/evidence id、类型、证据、属于哪一类（事实错误 / 过度延伸 / 独立观察 / 措辞 / 审查误判）、建议操作、是否造成跨页重复。
- 只修可明确定位的问题。最小操作：KEEP / REMOVE_ITEM / REPLACE_ITEM / REPHRASE_CLAIM / RECOMPOSE_LOCAL / NEEDS_REVIEW；不默认 REWRITE_PAGE。
- 局部修复后验证：新内容、跨页重复、原问题是否消失。同一缺陷最多再试一次模型，仍失败就 NEEDS_REVIEW。
- 第 21 页：不再带回"回答问题 76.0%"等 AI 使用目的；围绕短视频时长、覆盖、增长、运营组织；需要对比 AIGC 时做成明确的双指标观察。检查被移除事实不会因恢复回来。
- 第 29 页：锁定原叙事任务，不改投他章。

## P1-1 补足 PowerPoint 检查（只做本轮确认的共性问题）
- A：异常短尾行：单字、单字加标点、单独标点、残缺数字单位等；考虑标题有意分行。优先在布局阶段按真实字宽分配，不删标点、不缩字号。
- B：第 14 页过紧要给可执行建议：冲突对象、字形范围、当前与最低间距、谁能动；优先局部重分配空间，不缩核心数字。
- C：第 25 页色块：区分超出画布 / 超出内容安全区 / 有意出血 / 非预期覆盖 / 主视觉过大；按主题安全边距检查。
- D：第 23 页数字与单位作为语义组审查：可以分行，但关系要明确。
- 前后 PowerPoint 截图；旧问题能检出，修复后通过；不放宽阈值。

## P1-2 Defect → Repair
- 每个缺陷记录：defect_id、slide_id、defect_type、affected、修复操作、before_hash、after_hash、resolved、regression_status。
- 修复后重查同一缺陷；新引入事实、重复或几何问题时自动回滚。
- 第 14、21 页状态只能是 VERIFIED_FIXED 或 NEEDS_REVIEW。

## P1-3 审查误报与内容损失
统计以下各项：真实事实/关系错误、措辞问题、误报、改后提升、改后退化、移入备注而消失的有效事实。
独立而真实的多观察不应机械删除；审稿意见只是候选发现。

## P2 冻结快照与交付验收
- 不做新的 35 页端到端生成：冻结内容与版式决策 → 从快照组装 → PowerPoint 导出 → 全页审查（语义、数值、图表、几何、构图、投影可读）。
- 同一快照组装审核 3 次，结果一致。页数由保留页决定。
- 状态区分 AUTO_CHECK_PASS / VISUAL_SIGNED_OFF / NEEDS_REVIEW / RELEASE_READY；全部过关才打 release candidate。

## 必须满足
- 三次重放一致；五张有裁决；第 21 页不混 AI 使用目的。
- 第 13 页无"个，"折行；第 14 页不贴；第 25 页色块合规；第 23 页数字单位关联明确。
- 无新重复或无据结论；图表核对通过；完整逐页检查；基准不变。

## 不要
- Layout IR、重做设计语言、大量新规则、以首次通过率为目标、整页/整套重生成、无上限重试。
- 让审稿模型反复自由重写、用缓存跳过必要失效、把随机生成与冻结重放混为一谈。
- 强制 34 页、把 AUTO_PASS 称为签收、改阈值掩盖缺陷、覆盖基准、100 页。
