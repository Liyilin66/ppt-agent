# P4-Fix2 任务（来自 ChatGPT「分析PPT美学问题」对话，第 1 轮回复，2026-11-18）

用户授权的工作循环：Claude Code 把每轮结果发给该对话，按其回复的 prompt 执行，再发回结果。以下为要点摘录（全文在对话中）。

目标：正确性封闭 + 全局内容规划 + 首次设计质量提升。严格按 P0 → P1 → P2。

## P0
- P0-1 指标可比性与时间语义：序列保存指标身份、单位、度量类型、统计对象、时间、数据状态（observed/forecast/unknown）、精度、类别、证据、完整性。
  只有可比较的值才能共用定量轴；表格一列不能因为都是数字就成为序列（第 9 页）。预测状态只由明确的预测语义决定，
  "到 2025 年""截至 2025 年"不算（第 20 页）；状态不明不得套用实测或预测的视觉编码。加反例测试。
- P0-2 视觉数值保真：柱从零起、比例条、方块阵（96.8% 不能画成 10 格全亮，第 11 页）、饼图整体、近似值、节选（写明"前三位/节选"）、类别标签。
  第 4 页设备图要核对原图，区分缺数据、提取失败、节选。
- P0-3 论点与证据双向验证：图表、文字事实都要支持论点；不相关的事实移除或替换（第 20、23、4 页）。
- P0-4 策划失败显式化：记录错误类型与批次；不能把"策划为空"当"没有重复"；模拟 37 页以上、某批截断，系统须重试或停止并给出诊断。

## P1
- P1-1 全局内容登记表（论点、增量、领衔指标、证据、序列 ID、原图 ID），全篇两两比较；数据身份、图表身份、论点语义都比；
  真正重复的在大纲层合并、重分或改讲；证据不足可减页（第 14/15、16/31 页）。
- P1-2 设计前容量预测：先按逐次记录统计首次失败类别（高度溢出、宽度溢出、重叠、图表尺寸、文本框过窄、数字单位折行、双焦点、密度超容量、其他），
  再把容量预测前移。分开记录 A 原始直接通过、B 几何修复后、C 重试后、D 兜底。目标 A ≥ 30%、B ≥ 70%、D = 0，不得为数字降标准。
- P1-3 格式性兜底与断行：数字单位拆分、过窄文本框、类别名恢复后标题生硬、双焦点、小字可读性（第 10、12、22、23、26、35 页）。

## P2
定向回归（第 4、9、10、11、14、15、16、20、22、23、26、31、35 页）→ 冻结打标签 → 同一份报告空设计缓存全新运行（属回归，不是新资料测试），
允许按资料调整页数。提交 PPTX、导出图、缩略图、逐次缺陷记录、四阶段通过率与兜底率、调用与费用、全局重复报告、图表核验、未通过页面、对比上一轮、是否达标结论。

## 禁止

大量新模板/配色/装饰；未经 PowerPoint 导出验证就宣布通过；把模型改写的标签当原文名称；把修复后成绩冒充冻结首次成绩。
