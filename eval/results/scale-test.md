# 规模验证：一次性生成 50 页与 100 页（2026-11-19）

目的：验证系统能否一次性跑完长篇。设计风格沿用现有 studio 主题（美观问题已另行搁置）。
两套都是英文资料 → 中文成稿，打开终审，未打开关键页择优。

| | 50 页 | 100 页 |
|---|---|---|
| 资料 | IEA《Global EV Outlook 2025》，173 页 | BOND《Trends – Artificial Intelligence》，340 页 |
| 请求页数 | 50 | 100 |
| 页数预算（内容页） | 41 → 30 有足够独立事实 | 89 → 76 有足够独立事实 |
| 成品张数 | 39 | 87 |
| 章节 | 6 | 8 |
| 自动通过 | 29 / 39 | 74 / 87 |
| PowerPoint 文字碰撞 | 0 | 0 |
| 原生图表 / 原文图 | 0 / 0 | 1 / 1 |
| 生成用时 | 56 分钟 | 约 85 分钟（崩溃前约 46 分钟 + 续跑 38 分钟） |
| 写作模型费用 | $7.18 | 续跑 $3.50；崩溃前部分未记录（估计 $4～6） |

页数服从资料容量：成品少于请求的页数，是系统判断其余页面没有独立事实可写，不是生成中断。

## 跑长篇时发现并修复的问题
1. **英文财经缩写不认（P1）**：BOND 里 252 个"800MM / 5.5B / 27K / $3.3T"只认得 114 个，页数预算因此只给 36 页。
   修复后同一份资料给到 76 页（`c1c3397`）。
2. **崩溃（P0）**：终审把无关条目移进备注时，假设每个条目都有"数值"字段，普通要点页没有，100 页那套在第 46 分钟崩溃。
   修复（`b8f3030`）后续跑：前面的内容全部来自缓存，3 秒越过崩溃点，没有重新生成。这也验证了断点续跑。

## 仍然存在的问题
- **第 19 张（100 页）几乎是空页（P0）**：这一页的数字核对没通过，资料前后数字不一（247 / 248），被拒数字移走后只剩章节名，
  但页面没有被删除。门禁拦下了它，但应该在流水线里直接删掉这类空页。**未修复。**
- 两套都有 9～13 张待复核：句末一两个字单独成行（P2）、少量内容待复核。
- 100 页那套后半部分（第 4～8 章）以文字列表为主，数字和图明显少；图表和原文图几乎没有用上。
- 设计风格不变（米色、红、细线），美观问题另行处理。

## 结论
系统可以一次性跑完 50 页和近 90 页的长篇：生成、核对、终审、续跑、PowerPoint 导出都正常，没有文字碰撞。
需要在写进简历前修掉的只有一处：空页没有被删除。
