# P5 · P1-A 原文图表发现与核验（IEA 样本）

## 问题
IEA 正文的图表是**矢量绘制**的（没有嵌入图片），也没有"图 N / Figure N"编号，靠"IEA. CC BY 4.0. / Notes: / Sources:"标注出处。
原有的提取只找"图 N"图注 + 嵌入位图，所以 173 页报告一张图也没找到。

## 做了什么（通用，不针对 IEA）
- `figure_discovery.py`（新依赖 pypdfium2，Apache/BSD 许可）：把页面上密集的绘图对象聚成一组；上沿是紧贴图形的图题（向上最多三行），
  下沿是出处行（Sources/Notes/IEA. CC BY/资料来源/来源）；按读者看到的样子渲染成 PNG（含坐标轴、图例、标签）。
  - 排除：整页高的底色文本框（侧栏）；全是细线、描边或白底单元格的区域（表格，走 `tables` 的数据通道）。
  - 已有的"图 N + 位图"页面保持原样；只在没有配对图注的页面补充。CNNIC 冻结快照从缓存读图，不受影响。
- 读图核验仍用原来的 `figures.assess`（两次独立读图一致、对照原图复核才可重画；数值没印在图上不估计）。两处调整：
  - "元素超过 24 个就读不过来"只用于结构图和流程图；数据图表靠形状读，只看最小字号。
  - 原图允许通栏放（最宽 960 像素），按这个宽度判断字能否看清；需要通栏时，设计提示和版面检查都会要求图占 11～12 列。

## 结果
IEA 全书发现 63 张图（排除表格和侧栏后）。8 张代表图样本（堆叠柱状时间序列、季度、双轴柱线、正负条形、分面小图、折线 + 散点、100% 堆叠、销量与份额组合）：

| 结果 | 张数 |
|---|---|
| 原生可编辑图表（VERIFIED_NATIVE_CHART） | 0 |
| 原图引用（SOURCE_FIGURE），通栏可读 | 8（最小字 11～13 像素，需宽 750～880 像素） |
| 拒绝（REJECTED） | 0（放宽前：7 张因元素数、8 张因字号被拒） |
| 数据核验错误 | 0（没有任何估读数值进入图表） |

8 张都没有把数值印在图上，按规则不能估读成精确图表，所以原生图表为 0。这是正确结果，不是缺陷。
IEA 的原生图表只能来自正文写明的数据序列（已修复"USD 40 400"单位在前的问题）；官方数据文件（Global EV Data Explorer）不在本次授权范围内，未使用。
